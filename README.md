# YCNet RIO + RUDP

A recovery and improvement project for the original YCNet networking code.

Current scope:
- Windows Registered I/O (RIO) UDP transport
- Reliable UDP sequence / ACK / retransmission layer
- Regression and integration tests before behavior changes
- Planned authoritative multiplayer demo and network-condition benchmarks

The original public repositories remain untouched as historical references. This repository is the maintained portfolio version.
